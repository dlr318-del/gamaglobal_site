Быстрый старт и профессиональное сопровождение

01 / СТАРТ

Быстрый старт

Благодаря почти 35-летнему опыту, библиотеке готовых интерфейсов и программным роботам, система начинает приносить пользу с первых дней.

02 / ТРУДОЗАТРАТЫ

Снижение трудозатрат на внедрение

Активное участие команды клиента ускоряет процесс в 5–10 раз за счёт точного определения болевых точек, требований к системе и предоставления необходимых данных.

03 / ЭКСПЕРТИЗА

Профессиональное сопровождение

Команда поддержки и консультанты с глубокими знаниями в предметной области (учёта и оценки активов, портфельного анализа).

04 / РЕЕСТР

Соответствие требованиям

GAMA включена в Единый реестр российского ПО (№ 7153).

05 / СЕРВИС

Уникальный сервис

GAMA может поставляться вместе с сервисом по удалённому наполнению системы рыночными и портфельными данными, сверками со сторонними источниками, выявлением и устранением ошибок.

06 / ИНТЕГРАЦИЯ

Большое количество готовых интерфейсов

Сибондс, RUDATA, НРД, ММВБ, ЦБ РФ, отчёты брокеров, УК, внутренних систем.

Технологические и интеграционные преимущества

  • Собственное безопасное хранилище данных: данные можно прочитать только с помощью самого комплекса GAMA, что многократно повышает защиту от утечек информации
  • Широкие возможности интеграции: большое количество готовых интерфейсов для подключения к внешним источникам данных
  • Мощные средства отчётности: генератор отчётов и документов (в т.ч. на двух языках), конструктор аналитических панелей (дашбордов), GAMA Export для выгрузки данных во внешние системы
  • Автоматизация рутины: GAMA Agent, GAMA Agent Market, GAMA Terminal
