Как работает сравнение с моделью?

Портфель Бенчмарк РЕЗУЛЬТАТ
Единая аналитическая среда

Алгоритм:

  1. Все активы портфеля распределяются по категориям (акции, гос. облигации по дюрации, корп. облигации по дюрации, муниципальные облигации, денежные эквиваленты).
  2. Для каждой категории рассчитывается вес (доля в общей стоимости портфеля без учёта доходов/расходов) на начальную дату.
  3. С Мосбиржи загружаются исторические данные соответствующих индексов за тот же период.
  4. Для каждого индекса рассчитывается годовая доходность за период отчёта.
  5. Вклад категории = Вес категории × Годовая доходность индекса.
  6. Доходность модели = Сумма вкладов всех категорий.
  7. Альфа (превышение) = Реальная доходность портфеля (MWR) − Доходность модели.

Числовой пример:

Портфель: Акции 25% (индекс MCFTR +20% годовых), Облигации 30% (индекс +8% годовых), Деньги 25% (RUSFAR +4% годовых)

Вклад акций: 0.25 × 20% = 5.00%
Вклад облигаций: 0.30 × 8% = 2.40%
Вклад денег: 0.25 × 4% = 1.00%
Доходность модели: 5.00% + 2.40% + 1.00% = 8.40%
Реальная доходность портфеля (MWR): 15.94%
Альфа (превышение): 15.94% - 8.40% = +7.54%

На что обратить внимание при анализе:

  • Положительная альфа — ваш портфель показал результат выше модельного (индексов). Это может быть следствием удачного выбора бумаг или правильного timing ввода/вывода денег.
  • Отрицательная альфа — модельный портфель оказался доходнее вашего. Стоит пересмотреть структуру или управление.
  • Если для какой-то категории нет индекса (например, корп. облигации до 1 года или муниципальные более 3 лет), она исключается из модели, что может искажать результат.
  • Денежные средства, депозиты и РЕПО сравниваются со ставкой RUSFAR (рыночная ставка overnight, отражает альтернативные издержки).
  • Правый клик на строке категории показывает список всех бумаг, вошедших в эту категорию, с их MWR, дюрацией и стоимостью.
  • Чем крупнее вес категории, тем больше её влияние на итоговую доходность модели.

Данные индексов предоставлены Московской Биржей через публичное API (ISS). Доходность индексов рассчитана как годовая (аннуализированная) за период отчёта.

Алгоритм распределения активов по категориям:

  1. Сначала проверяется поле «Тип актива».
  2. Если «Тип актива» = «Акции»:
    • подкатегория «Паи» (ПИФы, БПИФ, ETF) → Денежные эквиваленты
    • остальные акции → Акции
  3. Если «Тип актива» = «Облигации»:
    • «Категория балансового учета» содержит «ГЦБ» или «Государственные» → Государственные облигации
    • «Категория балансового учета» содержит «Корпоративные», «Субфед», «Гос. корпораций» или «Ипотеч» → Корпоративные облигации
    • «Категория балансового учета» содержит «Муницип» → Муниципальные облигации
  4. Если «Тип актива» = «Доходы/расходы» → Денежные эквиваленты
  5. Если «Тип актива» = «Депозиты» → Денежные эквиваленты
  6. Если «Тип актива» = «РЕПО» → Денежные эквиваленты
  7. Если «Тип актива» = «ДС» или категория содержит «Брокерский счет»/«Расчетный счет» → Денежные эквиваленты
